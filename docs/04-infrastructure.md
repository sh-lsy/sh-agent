## 1. 核心技术矩阵

* **记忆系统 (Memory)**：内存向量检索 (Vector Store)、滑动窗口短期记忆。
* **上下文工程 (Context Engineering)**：Token 预算管理、历史会话动态摘要压缩。
* **通信协议 (MCP - Model Context Protocol)**：使用 TypeScript 实现标准 MCP Client / Server。
* **自动化评估 (Evaluation)**：Agent 基准测试用例集与评分维度。
