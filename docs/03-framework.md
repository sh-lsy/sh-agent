## 1. 架构目标

前端开发者习惯了 Vue 3、Pinia、Vite 这类高内聚、易扩展的现代前端工程。我们自研的 TypeScript Agent 框架同样追求：
1. **轻量极简**：拒绝重度黑盒抽象，核心引擎代码控制在千行以内。
2. **组合式 API**：类似 Vue 3 `setup` 风格，通过可插拔的插件（Plugins/Hooks）增强 Agent 能力。
3. **事件驱动**：支持订阅 Agent 的每个思考与调用阶段，方便流式呈现到前端界面。
